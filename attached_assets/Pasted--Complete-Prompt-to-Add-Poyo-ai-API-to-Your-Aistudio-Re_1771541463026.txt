3. Find **"API Keys"** or **"Custom API"** section
4. Click **"+ Add Custom Provider"** or **"+ New API"**
5. Fill in:
   - **Name:** Poyo AI
   - **API Key:** `sk-NdIelDiC8dgJXP-uSy-4_03BQnGaCX1xdtVYZXXXFqXF3oProuUg9huz_`
   - **Base URL:** `https://api.poyo.ai/v1`
   - **Model:** `claude-sonnet-4.5`
6. Click **Save**
7. Go to chat interface → Select **"Poyo AI"** from model dropdown

## 🔧 **If You're Coding it Manually in Replit:**

Create a file called `poyo-config.js`:

```javascript
import OpenAI from 'openai';

export const poyoClient = new OpenAI({
  apiKey: 'sk-NdIelDiC8dgJXP-uSy-4_03BQnGaCX1xdtVYZXXXFqXF3oProuUg9huz_',
  baseURL: 'https://api.poyo.ai/v1'
});

export async function chat(userMessage) {
  const response = await poyoClient.chat.completions.create({
    model: 'claude-sonnet-4.5',
    messages: [
      { role: 'user', content: userMessage }
    ]
  });
  
  return response.choices[0].message.content;
}
```

Then use it anywhere:
```javascript
import { chat } from './poyo-config.js';

const reply = await chat('Hello!');
console.log(reply);
```
